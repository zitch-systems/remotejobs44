About the role

Vercel is looking for a Senior Frontend Engineer to help build the products that power the modern web. You'll work on highly-visible, performance-critical interfaces used by millions of developers — from the dashboard to the deployment experience — collaborating closely with design and platform teams across time zones.

This is a fully remote role open to candidates worldwide — we hire across time zones, not borders. We optimise for written communication, autonomy, and shipping thoughtfully.

What you'll do

  • Build and own complex, accessible interfaces in React and TypeScript.
  • Partner with design to turn ambitious concepts into polished, fast experiences.
  • Set the bar for performance, raising Core Web Vitals across the product.
  • Mentor engineers and contribute to a thoughtful, kind code-review culture.

What we're looking for

  • 5+ years building production web applications with React.
  • Deep understanding of browser performance and rendering.
  • Strong written communication for an async, distributed team.
